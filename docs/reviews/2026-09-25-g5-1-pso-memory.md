## 实现(`generation/optimizers/pso.py`,name = `pso`)

USPEX-PSO 无速度向量,"速度"即算子选择概率。按槽位记忆映射:

* **粒子记忆**:每槽位 `_Particle`(当前位置 + pbest[历史最优,含轮内 z
  分数与缩放描述符]);gbest = 全体 pbest 之最;
* **距离调制拉力**:每个子代的变异目标由竞争质量决定——
  `P_p = U·w_pbest·d(pos, pbest)`、`P_g = U·w_gbest·d(pos, gbest)`、
  `P_m = U·w_mut`(拉向记忆目标 = 围绕该记忆结构提案);
* **移民重置**:固定份额(默认 0.15)回全新种子,优先级最高(USPEX 同款);
  首轮无记忆 = 全移民,分布与 Random 一致;
* **偏离 USPEX 之处(文档化)**:记忆比较用**轮内标准化 fitness(z 分数)**——
  USPEX 比较焓(时间不变量),而本系统 fitness 是 novelty 型、随档案增长
  衰减,原始值跨轮比较会系统性偏向早期结构;
* 无 genome/mask:算子按用户配置参数、均匀抽取——本项测的是**记忆导航**。

参数:`pso_weight_pbest=1.0 / gbest=1.5 / mut=0.5`、`immigrant_fraction=0.15`;
parse_request 校验(至少一个权重 > 0);catalog + 前端全套(类型/默认值/
提交/UI 拉力参数/中英文/preview);测试 18 个
(`tests/test_generation_pso.py`:记忆更新、z 数学、几何拒绝忽略、
距离调制目标选择、移民份额、registry/parse 边界)。全量 **582 passed + 1 skipped**。

## 结论

1. **先验兑现**:无 crossover 的记忆导航不提供 GA 之外的增量——discovery
   均值与 GA 持平,中位数更差(12.6 vs 15.4),方差全场最高(±11.89),
   coverage 反而显著劣化(+3.87)。gbest 集中带来的是方差而非收益。
2. **PSO 不作为推荐优化器**;UI 保留为可选项(其"围绕记忆结构提案"与
   target-region 的"围绕锚点提案"共享同一机制族)。
3. 计划原文(`06-plan-...expansion.md` §7 G5)的"PSO 标准更新
   x_i = [Δr_1..Δr_N, ε_xx, ...]"在结构坐标空间不可定义(G4 已论证:
   不同结构原子数/排列/晶胞不同)——memory-PSO 是与 G4 决策一致的
   唯一自洽映射;若未来实现 crossover( attraction 的几何形式),
   可依据 `2026-09-25-uspex-pso-analysis.md` 的选项 1 重新评估。
4. 计划中"10–20% random immigrants 防早熟"已内置(`immigrant_fraction=0.15`)。

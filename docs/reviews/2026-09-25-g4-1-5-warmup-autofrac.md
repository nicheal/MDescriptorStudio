# 2026-09-25 — G4-1.5 暖启动/AutoFrac 实验记录(默认回退 v1)

前置:G4-2(`2026-09-25-g4-2-random-vs-ga-benchmark.md`)诊断出 GA 的
"开局谱系锁定"失败模式后,本轮实现三个针对性杠杆并做同协议复测。
**结果:机制达到了设计目的(坍缩消失)但全预算净效果为负,默认已回退
G4-1 行为;机制保留为构造参数。**

## 实现(均在 `generation/optimizers/genetic.py`)

1. **暖启动扁平轮盘**:池条数 < `pressure_warmup_pool` 时,父代从全池
   均匀抽取(parent_fraction 截断与平方累加轮盘都不生效)。
2. **移民份额退火**:冷池期从 0.4 线性退到用户配置值(只升不降)。
3. **AutoFrac 乘子**:每算子 accepted/proposed 相对均值 →
   `0.55 + 0.45·rel`,夹紧 [0.5, 2.0],乘到基因 mask 权重;无提案算子
   保持中性。USPEX `update_STUFF` 的成功率自适应机制。

构造参数:`pressure_warmup_pool`(默认 0 = 关)、`autofrac`(默认 False)。
**当前默认 = 纯 G4-1 行为**(warmup=0 时 `_pool_is_warm()` 恒真,退火不
触发,AutoFrac 短路返回 1.0),与 G4-2 sweep 测得的最优 GA 变体逐路径一致。

## 证据

**Pilot(坍缩窗口)**:seed 1000、2000 evals,round 2–4 unique =
98/113/90(G4-1 同窗口曾跌到 8–23)——设计目标达成。

**全量复测**(20 seeds × 3 配置 × 10000 evals,`benchmark/results/20260925T090608Z/`,
对照 v1 = `20260925T042355Z/`;random 与 random-reuse 两轮逐位一致,
harness 确定性得到交叉验证):

| | v1 (G4-1) | v2 (G4-1.5) |
| --- | --- | --- |
| genetic unique/100 | 18.86 ± 8.64 | 16.29 ± 7.55 |
| 成对 genetic − random | −6.45,7/20 胜 | **−9.02,3/20 胜** |
| coverage radius 成对差 | −1.67(11/20 更好) | −0.30(10/20 更好) |
| genetic 最大值(运气上限) | 33.1 | 29.7 |

## 结论

1. **暖启动修了坍缩也砍了上限**。轨迹对比:坍缩型 seed(1000/1001)
   改善,但运气型 seed(1003:v1 靠激进轮盘放大好谱系拿到 117–155 的高产
   轮)被均匀选父抹平到 ~85。压方差与压上限同源;最终 unique/100 标准差
   只从 8.64 收到 7.55,均值反而下降。
2. **AutoFrac 未证明收益**(与暖启动/退火联合施测,无法归因单杠杆;
   假说:累计成功率让"局部高产"的算子(位移)热手赢者通吃,mask 收窄,
   牺牲了算子多样性——未单独验证)。
3. **结构性判断确认**:discovery 指标下,任何"从已接受池集中提案"的流
   都打不过均匀种子采样。这不是参数问题,是池集中提案与"发现新环境"
   目标之间的结构性错配。
4. **决策**:默认回退 v1(两个 headline 指标上都是实测最优的 GA 变体);
   G4-1.5 机制参数化保留。**不在同一批 20 seed 上继续做单杠杆消融**——
   那是对基准过拟合;若未来重启,需要新数据集/新指标假设。

## 对 G5 的输入

- GA 的现状定位:比 random-reuse 强 14–16/20,比 random 弱;coverage
  模式下有微弱优势。作为 UI 可选项保留,不作为默认推荐。
- 真正的"导航"能力(在 descriptor 空间朝目标移动)需要 crossover/吸引
  类算子——见 `2026-09-25-uspex-pso-analysis.md` 的 PSO 分析与三个选项。
- External adapter(G5 其余部分)不受本结论影响,随时可做。

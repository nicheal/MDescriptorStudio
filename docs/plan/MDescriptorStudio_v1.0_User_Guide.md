# MDescriptorStudio v1.0 User Guide

## 1. 软件简介

MDescriptorStudio 是面向材料模拟和机器学习势函数开发的科学计算平台。

主要功能：

-   结构数据管理
-   描述符计算
-   描述符空间分析
-   数据筛选
-   机器学习势工作流
-   结果可视化

支持：

-   SOAP
-   ACSF
-   ACE
-   MACE
-   DeepMD等描述符和模型体系扩展。

# 21. 常见问题

## Q1：计算速度慢

检查：

-   数据规模
-   CPU/GPU配置
-   descriptor参数

------------------------------------------------------------------------

## Q2：结果无法复现

检查：

-   descriptor版本
-   参数
-   数据fingerprint
-   软件版本

------------------------------------------------------------------------

## Q3：PCA图是否代表完整结构空间？

不一定。

需要同时查看：

-   explained variance
-   feature dimension
-   sampling方法

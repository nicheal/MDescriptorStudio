# MDescriptorStudio v1.0 Security and Data Governance Design

## 1. 设计目标

Security and Data Governance 用于保证 MDescriptorStudio 在：

-   本地科研环境
-   实验室服务器
-   HPC集群
-   多用户部署环境

中的安全运行。

目标：

实现：

-   数据安全
-   权限控制
-   可追溯管理
-   安全扩展
-   长期科研数据保存

------------------------------------------------------------------------

# 2. 安全架构

总体结构：

    User

     |

     |

     |

    Workflow Engine

     |

    Scientific Engine

     |

    Storage Layer

# 3. 安全设计原则

## 3.1 最小权限原则

用户和插件只能访问：

必要资源。

禁止：

-   任意文件访问
-   任意系统命令执行
-   未授权数据读取

------------------------------------------------------------------------

## 3.2 数据可追溯原则

所有科学结果必须关联：

    Dataset

    +

    Software Version

    +

    Parameters

    +

    Environment

    +

    User Operation

------------------------------------------------------------------------

    Permission Check

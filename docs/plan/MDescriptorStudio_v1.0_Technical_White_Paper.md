# MDescriptorStudio v1.0 Technical White Paper

## 1. 项目概述

MDescriptorStudio
是面向材料计算、机器学习势函数开发和智能材料发现的新一代科学计算平台。

项目目标：

建立连接：

    Physics

    +

    Data

    +

    AI

    +

    Simulation

    +

    Experiment

的统一材料研发基础设施。

------------------------------------------------------------------------

# 2. 科学背景

现代材料研发面临：

-   材料空间巨大
-   高精度计算成本高
-   实验周期长
-   数据分散
-   知识难以积累

传统模式：

    ↓

    Simulation

    ↓

    Experiment

    ↓

    Analysis

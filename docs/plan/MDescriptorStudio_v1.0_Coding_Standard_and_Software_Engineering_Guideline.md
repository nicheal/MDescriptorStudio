# MDescriptorStudio v1.0 Coding Standard and Software Engineering Guideline

## 1. 文档目标

本规范用于指导 MDescriptorStudio 长期开发和维护。

目标：

-   提高代码可读性
-   降低维护成本
-   保证科学计算可靠性
-   支持多人协作开发
-   提升开源项目质量

适用于：

-   Python Backend
-   Rust/Tauri Layer
-   React/TypeScript Frontend
-   Plugin Development
-   Scientific Algorithm Modules

------------------------------------------------------------------------

# 2. 软件工程原则

## 2.1 科学正确性优先

科学计算代码必须：

-   明确输入
-   明确输出
-   记录参数
-   保存版本信息
-   提供测试

------------------------------------------------------------------------

## 2.2 模块职责单一

禁止：

一个模块同时负责：

-   数据读取
-   算法计算
-   UI通信
-   文件保存

推荐：

    Data Layer

    ↓

    Algorithm Layer

    ↓

    Service Layer

    ↓

    Interface Layer

------------------------------------------------------------------------

## 2.3 显式优于隐式

避免：

-   隐式全局变量
-   自动修改状态
-   魔法参数

推荐：

明确：

``` python
result = analyzer.run(
    data,
    parameters
)
```

------------------------------------------------------------------------

# 3. Python代码规范

遵循：

PEP 8

推荐：

Python \>=3.10

------------------------------------------------------------------------

# 4. Python命名规范

## 类名

使用：

PascalCase

示例：

``` python
DescriptorEngine

StructureFrame

DatasetManager
```

------------------------------------------------------------------------

## 函数

使用：

snake_case

示例：

``` python
calculate_descriptor()

load_dataset()
```

------------------------------------------------------------------------

## 常量

使用：

UPPER_CASE

示例：

``` python
DEFAULT_CUTOFF = 5.0
```

------------------------------------------------------------------------

# 5. Python类型注释

必须使用：

type hints

推荐：

``` python
def compute(
    structure: StructureFrame
) -> DescriptorObject:
    pass
```

------------------------------------------------------------------------

# 6. Python模块结构

推荐：

    module/

    __init__.py

    core.py

    schema.py

    utils.py

    tests/

------------------------------------------------------------------------

# 7. Python异常处理

禁止：

``` python
except:
    pass
```

------------------------------------------------------------------------

推荐：

``` python
try:
    result = compute()

except DescriptorError as e:
    logger.error(e)
    raise
```

------------------------------------------------------------------------

# 8. 日志规范

禁止：

大量print。

使用：

``` python
logger.info()

logger.warning()

logger.error()
```

------------------------------------------------------------------------

日志必须包含：

-   时间
-   模块
-   Job ID
-   Dataset ID

------------------------------------------------------------------------

# 9. 科学算法代码规范

每个算法必须包含：

## 输入

说明：

-   类型
-   单位
-   范围

## 输出

说明：

-   数据结构
-   单位
-   精度

## 算法版本

例如：

    KernelAnalysis v1.0

------------------------------------------------------------------------

# 10. 数值计算规范

必须考虑：

-   浮点误差
-   数值稳定性
-   边界条件

禁止：

直接比较：

``` python
a == b
```

推荐：

``` python
abs(a-b)<tol
```

------------------------------------------------------------------------

# 11. 数据对象规范

禁止：

大量传递裸：

``` python
numpy.ndarray
```

推荐：

使用：

    StructureFrame

    DatasetObject

    DescriptorObject

    FeatureMatrix

保证：

-   元数据
-   来源
-   版本

------------------------------------------------------------------------

# 12. Rust/Tauri规范

## Rust职责

负责：

-   IPC
-   生命周期
-   安全
-   进程管理

不负责：

-   科学算法

------------------------------------------------------------------------

# 13. Rust命名规范

结构体：

``` rust
DescriptorManager
```

函数：

``` rust
load_dataset()
```

变量：

``` rust
dataset_id
```

------------------------------------------------------------------------

所有消息必须：

包含：

``` json
{
"id":"",
"method":"",
"params":""
}
```

------------------------------------------------------------------------

错误必须：

返回：

``` json
{

"message":""
}
```

# 15. React/TypeScript规范

## 组件

PascalCase：

``` tsx
DescriptorPanel
DatasetViewer
```

------------------------------------------------------------------------

camelCase：

``` tsx

useWorkflow()
```

推荐：

    datasetStore

    analysisStore

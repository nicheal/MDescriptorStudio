# MDescriptorStudio v1.0 Research Proposal and Funding Strategy

## 1. 项目定位

MDescriptorStudio 是面向未来材料科学研究的新型智能计算基础设施。

项目目标：

构建：

    Data

    +

    Physics

    +

    AI

    +

    Simulation

    +

    Experiment

融合的材料研发平台。

------------------------------------------------------------------------

# 2. 项目科学意义

现代材料研发面临：

-   材料空间巨大
-   高精度计算成本高
-   实验周期长
-   数据孤立
-   知识难积累

需要发展：

数据驱动与物理约束融合的新型材料研究模式。
